Boite — development sandboxes

Bare-metal dev environments in QEMU virtual machines, spun up from a baked base image.

boite-base.qcow2  ·  ~2 GB  ·  Debian 13 Download base image

What's inside

  • Debian 13, provisioned at build time — no cloud-init
  • Go, Rust, Bun, mise, Python toolchain baked in
  • boite user with passwordless sudo, zsh + starship, tmux

Install the CLI

curl -fsSL https://raw.githubusercontent.com/FacileStudio/boite/main/install.sh | bash
boite create my-sandbox

The CLI fetches https://boite.facile.studio/base.qcow2 on first create and verifies its SHA-256.
